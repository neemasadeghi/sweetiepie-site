# Landing video (optional local fallback)

**Preferred:** upload via **Sanity Studio → Landing page → Landing video (Mux)**.  
That uses the same Mux setup as your project preview clips — no files in this folder needed.

If you ever want a file-based fallback instead, add:

- `hero-landscape.mp4` — 16:9, 1920×1080 min
- `hero-portrait.mp4` — 9:16, 1080×1920 (optional)

Export: H.264, no audio, 5–15 sec loop.
